# ru-passport — сканер и парсер паспорта гражданина РФ

Распознаёт внутренний паспорт РФ по фото или скану разворота, а также разбирает уже считанную
машиночитаемую запись (MRZ). Результат проверяется по контрольным цифрам и логическим правилам.

## Что умеет

- **Разбор MRZ** внутреннего паспорта (2 строки × 44 символа, формат МВД):
  ФИО, серия и номер, пол, дата рождения, дата выдачи, код подразделения.
- **Точное ФИО на кириллице.** В MRZ используется таблица транслитерации МВД (Ё→2, Ч→3, Ш→4,
  Щ→W, Ъ→X, Ь→9, Э→6, Ю→7, Я→8 …). Она взаимно однозначна, поэтому ФИО восстанавливается без
  потерь, в отличие от ICAO-транслитерации загранпаспорта.
- **Все 4 контрольные цифры** (серия/номер, дата рождения, доп. поле, итоговая).
- **Исправление ошибок OCR:**
  - кириллические двойники (`Р`→`P`, `О`→`O`), `«`→`<`, буквы в цифровых полях (`O`→`0`, `B`→`8`);
  - в ФИО цифры 0, 1, 5 невозможны, поэтому они заменяются на O, I, S;
  - мусор в заполнителе строки 1 (`<<<K<<S<`);
  - одна неверная цифра исправляется по контрольной цифре, **только если вариант единственный**.
    Если подходят несколько вариантов, парсер не угадывает, а сообщает об ошибке.
- **Сверка с визуальной зоной:** из неё берутся «Паспорт выдан» и «Место рождения» (в MRZ их нет).
  Остальные поля сравниваются с MRZ. Неоднозначная ошибка в MRZ исправляется по визуальной зоне,
  только если с этим значением сходится контрольная цифра.
- **Голосование по кадрам** (`MRZAccumulator`) для видеопотока с камеры.
- **Проверки:** срок действия (замена в 20 и 45 лет, 90 дней на замену), выдача не раньше 14 лет
  и не раньше 01.10.1997, даты не в будущем, регион по серии (ОКАТО), год бланка, форматы.
- **Обработка изображения:** выравнивание наклона (проекционный профиль), автоповорот 0/90/180/270°,
  поиск зоны MRZ морфологией, несколько вариантов бинаризации, вертикальная серия/номер у края.

## Установка

```bash
pip install -e .            # только парсер MRZ, без зависимостей
pip install -e ".[ocr,dev]" # + распознавание изображений и тесты
sudo apt install tesseract-ocr tesseract-ocr-rus
```

## Использование

```python
from ru_passport import parse, scan, MRZAccumulator

d = scan("passport.jpg")                 # фото/скан разворота (путь, bytes или numpy)
d = parse("PNRUSIVANOV<<IVAN<IVANOVI3<<<<<<<<<<<<<<<<<<",
          "4601234561RUS9003152M<<<<<<<1100620770120<32")

d.surname, d.name, d.patronymic          # 'Иванов', 'Иван', 'Иванович'
d.series_number                          # '46 01 123456'
d.division_code, d.issue_date            # '770-120', date(2010, 6, 20)
d.status, d.valid_until                  # 'valid', date(2035, 3, 15)
d.is_valid, d.confidence                 # True, 1.0
d.issues                                 # ошибки/предупреждения с кодами
d.corrections                            # что было исправлено и почему
d.to_dict()                              # для JSON/API

acc = MRZAccumulator()                   # видеопоток: по строке OCR на кадр
for text in frames_ocr_text:
    acc.add_text(text)
d = acc.result()
```

Командная строка:

```bash
ru-passport scan passport.jpg
ru-passport mrz "PNRUS..." "4601234561RUS..."
```

Код возврата 0, если документ прошёл все проверки, иначе 1.

## Формат MRZ внутреннего паспорта

```
PNRUSIVANOV<<IVAN<IVANOVI3<<<<<<<<<<<<<<<<<<
4601234561RUS9003152M<<<<<<<1100620770120<32
│  │     │└┬┘└─┬──┘││└──┬──┘│└──┬─┘└─┬──┘│││
│  │     │ │   │   ││   │   │   │    │   ││└ итоговая контрольная
│  │     │ │   │   ││   │   │   │    │   │└ контрольная доп. поля
│  │     │ │   │   ││   │   │   │    │   └ заполнитель
│  │     │ │   │   ││   │   │   │    └ код подразделения 770-120
│  │     │ │   │   ││   │   │   └ дата выдачи 20.06.2010
│  │     │ │   │   ││   │   └ последняя цифра серии (460[1])
│  │     │ │   │   ││   └ срок действия не заполняется
│  │     │ │   │   │└ пол
│  │     │ │   │   └ контрольная даты рождения
│  │     │ │   └ дата рождения 15.03.1990
│  │     │ └ гражданство
│  │     └ контрольная серии/номера
│  └ номер 123456
└ три первые цифры серии
```

## Ограничения

- ФИО длиннее 39 символов обрезается в MRZ (ставится флаг `name_truncated`). Полное написание
  и дефисы (`Римский-Корсаков`) берутся из визуальной зоны, если она распознана.
- У строки 1 нет контрольной цифры, поэтому ФИО защищено только голосованием по вариантам OCR
  и сверкой с визуальной зоной.
- Серия → регион — подсказка по ОКАТО, а не строгая проверка.
- Проверка паспорта по базе недействительных паспортов МВД не входит в библиотеку.

```bash
pytest
```

`tests/test_ocr.py` генерирует синтетические сканы (наклон, размытие, поворот на 90° и 180°)
и прогоняет полный путь OCR. Без установленного tesseract эти тесты пропускаются.
